# 🎮 GameStore

Página de loja de games online construída com **React** + **Vite** e **Bootstrap 5**.

## ✨ Funcionalidades

- Header fixo com menu responsivo (mobile)
- Banner em carrossel
- Seção **Jogos em Destaque**
- Seção **Jogos em Lançamento**
- Estatísticas da loja
- Footer completo com links e contato
- Layout totalmente responsivo (mobile, tablet e desktop)
- Tema gamer escuro com gradientes e animações

## 🚀 Como rodar

```bash
# Instalar as dependências
npm install

# Rodar o servidor de desenvolvimento
npm run dev
```

Abra o endereço indicado no terminal (geralmente `http://localhost:5173`).

## 📦 Build de produção

```bash
npm run build
npm run preview
```
